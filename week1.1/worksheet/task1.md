# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists the files in current directory|
|     cd directory_name       | opens given directory. Applies to directories in the one currently accessed.|
|     cd ..                   | exit current directory into parent directory.|
|     cd -                    | outputs previous file path, change into previous file path|
|     mkdir directory_name    | create new directory/folder inside current directory|
|     touch filename          | create new file in currently accessed dir, file type should be specified using suffix. example- touch test.py |
|     git status              | outputs any changes in files that are to be commited(staged) as well if files have been modified |
|     git add -A              | stages all files. Shows git what you want saved|
|     git commit -m ""        | saves changes at a point of time. Past commits can be accessed. -m is a message to describe the changes |
|     git push                | save commited changes and message from local branch into main branch online (permanent and remote) (local->remote) |
|     git pull                | access code from remote environment in local branch (remote->local) |
